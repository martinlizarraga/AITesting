# Audio Separator

A modern web application that uses AI to separate instruments from audio files. Built with Next.js, React, and Tailwind CSS.

## Features

- Upload MP3 or WAV audio files
- Select instruments to remove (vocals, guitar, drums, bass)
- Dark mode support
- Mobile-friendly interface
- Real-time processing status
- Download processed audio files

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Usage

1. Click the upload area or drag and drop an audio file
2. Select the instrument you want to remove
3. Click "Process Audio"
4. Wait for processing to complete
5. Download the processed file

## Technologies Used
